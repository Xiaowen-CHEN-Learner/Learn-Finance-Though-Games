	About Dataset
	The basic idea of this dataset is to answer the question "if I invested $100 at the beginning of some year in some 	investment vehicle, how much money would that investment be worth by the end of the year?" To answer that 	question, I've gather data on inflation, the S&P 500, housing, bonds, and gold. Data sources - 	Inflation: https://www.macrotrends.net/datasets/2497/historical-inflation-rate-by-year, S&P 	500: https://www.slickcharts.com/sp500/returns, Housing and Bonds: https://www.macrohistory.net/database/, 	Gold: https://github.com/datasets/gold-prices/blob/main/data/annual.csv
